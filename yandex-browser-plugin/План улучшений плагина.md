## Инструкция для модели (как брать задачи из чеклиста)

**Всего 18 задач, 3 агента. Все работают параллельно.**

| Агент | Область | Задач | ~Время | Файлы |
|-------|---------|-------|--------|-------|
| **1 — Плагин** | Ответы API, ошибки, логи/история, UX даты | 9 | ~4ч | `yandex-browser-plugin/content.js` + связанные |
| **2 — FastAPI** | Рефактор сервера + тестовые эндпоинты | 7 | ~3ч | `src/app.py`, `src/utils.py`, новые файлы |
| **3 — Аналитика** | 2 анализа → MD, код не трогать | 2 | ~1ч | Чтение всех файлов, результат в `yandex-browser-plugin/` |

**Правила:**
1. **Агент 1** берёт секции «Обработка ответов API», «Ошибки», «Логи и история», «UX модалки — даты» целиком. Все задачи в одном файле плагина, поэтому одним агентом — без конфликтов.
2. **Агент 2** берёт «Рефакторинг FastAPI сервера» + «Тестовые эндпоинты». Делать по порядку: константы → роутеры → Pydantic → удаление injector-script → починка тестовых эндпоинтов.
3. **Агент 3** — ТОЛЬКО анализ, не трогать код. Результат — MD файлы в `yandex-browser-plugin/`.
4. Перед началом агент должен прочитать `AGENTS.md` для понимания архитектуры.
5. После выполнения задачи отметить `- [X]` в этом файле.
