# Установка расширения в Яндекс Браузер

Ничего собирать не нужно — расширение на чистом JS.

## Шаги

1. Открой Яндекс Браузер
2. В адресной строке введи `browser://extensions/`
3. Включи «Режим разработчика» (переключатель в правом верхнем углу)
4. Нажми «Загрузить распакованное расширение»
5. Выбери папку с расширением:
   ```
   yandex-browser-plugin/
   ```
6. Расширение появится в панели браузера — готово

## Использование

1. Открой страницу редактирования записи на `eopp.epd-portal.ru`
2. Появится кнопка «Инжектор» в правом нижнем углу страницы
3. Кликни по кнопке — инжектор откроется в новой вкладке

## Обновление после изменений

На странице `browser://extensions/` нажми кнопку обновления (⟳) под расширением.
